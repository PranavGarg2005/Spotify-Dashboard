# Spotify-Dashboard
A sleek and interactive Spotify-inspired analytics dashboard built to visualize music streaming insights such as total streams, artist performance, song popularity, and yearly trends.

🚀 Features
📊 Total Streams Overview
Displays total streams, average popularity, and song duration metrics
🎤 Artist Analytics
Songs count per artist
Distinct songs tracked monthly
🎶 Song Insights
Popularity comparison across top songs
Explicit vs non-explicit distribution
📅 Time-Based Trends
Streams per year (2023 vs 2024)
Monthly average popularity trends
🎵 Interactive Sidebar
Filter songs by artist/title
Dynamic selection support
🎨 Modern UI
Dark theme with Spotify-inspired design
Smooth and clean visual hierarchy
